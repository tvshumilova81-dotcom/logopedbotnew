# Telegram-бот для детского логопеда Татьяны Шумиловой

Полноценный коммерческий Telegram-бот на **aiogram 3.x**: запись на занятия, анкета
ребёнка, полезные материалы (бесплатные и платные за Telegram Stars), FAQ, профиль
пользователя и админ-панель с рассылками, статистикой и экспортом в Excel.

## Стек технологий

- Python 3.12
- aiogram 3.x (Routers, FSM, Middlewares)
- SQLAlchemy 2.0 (async) + SQLite (легко переключается на PostgreSQL)
- Alembic — миграции БД
- Docker / Docker Compose
- Telegram Stars — оплата цифровых материалов
- openpyxl — экспорт данных в Excel

## Структура проекта

```
config/            конфигурация (pydantic-settings)
database/          движок БД, базовые классы, модели SQLAlchemy
handlers/          хендлеры (роутеры aiogram) для пользователя
handlers/admin/    хендлеры админ-панели
middlewares/       DB-сессия, антиспам, логирование ошибок
states/            FSM-состояния (запись, анкета, админ-формы)
services/          бизнес-логика (booking, questionnaire, materials, export...)
keyboards/         inline/reply клавиатуры
filters/           кастомные фильтры (IsAdmin)
articles/          бесплатные статьи в формате Markdown
data/faq.json       вопросы и ответы FAQ
media/materials/   файлы платных и бонусных материалов
media/covers/      обложки материалов
logs/               лог-файлы (ротация)
alembic/            миграции БД
main.py             точка входа
```

## 1. Установка зависимостей (без Docker)

```bash
python3.12 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Создание бота через BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot` и следуйте инструкциям (укажите имя и username бота).
3. Скопируйте выданный **токен** — он понадобится в `.env`.
4. (Опционально) настройте описание, аватар и команды бота через `/setdescription`,
   `/setuserpic`, `/setcommands`.

## 3. Настройка `.env`

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните переменные:

| Переменная              | Описание                                                        |
|--------------------------|-------------------------------------------------------------------|
| `BOT_TOKEN`              | Токен бота от BotFather                                          |
| `ADMIN_IDS`               | Telegram ID администратора(ов) через запятую                    |
| `DATABASE_URL`            | Строка подключения к БД (по умолчанию SQLite)                    |
| `INSTAGRAM_URL`           | Ссылка на Instagram (единственный разрешённый контакт)          |
| `TELEGRAM_CHANNEL_URL`    | Ссылка на Telegram-канал                                         |
| `TIMEZONE`                | Часовой пояс проекта                                             |
| `LOG_LEVEL`               | Уровень логирования (INFO, DEBUG, WARNING...)                    |
| `THROTTLE_RATE_LIMIT`     | Минимальный интервал между сообщениями от одного пользователя, сек |

Свой Telegram ID можно узнать у бота [@userinfobot](https://t.me/userinfobot).

## 4. Запуск локально

```bash
python main.py
```

При первом запуске бот автоматически создаст таблицы БД (fallback без Alembic) и
добавит в каталог платный материал «30 речевых игр» из `media/materials/`.

### Использование Alembic (рекомендуется для продакшена)

```bash
alembic revision --autogenerate -m "init"
alembic upgrade head
```

## 5. Запуск через Docker

```bash
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f bot
```

Остановка:

```bash
docker compose down
```

Файлы БД, логи и материалы сохраняются в volume-папках `./data`, `./logs`, `./media`
— они не теряются при пересборке контейнера.

## 6. Переход на PostgreSQL

1. В `docker-compose.yml` раскомментируйте сервис `db` и `volumes: pgdata`.
2. В `.env` укажите:
   ```
   DATABASE_URL=postgresql+asyncpg://logoped:logoped@db:5432/logoped_bot
   ```
3. Установите `asyncpg`: добавьте `asyncpg` в `requirements.txt` и пересоберите образ.
4. Примените миграции: `alembic upgrade head`.

## 7. Настройка Telegram Stars

Telegram Stars — встроенная валюта Telegram, не требующая подключения внешнего
платёжного провайдера. В боте уже реализована отправка счёта (`send_invoice`) с
валютой `XTR`. Никаких дополнительных токенов провайдера не требуется — Stars
работают "из коробки" для любого бота.

После успешной оплаты бот:
1. Сохраняет покупку в БД.
2. Автоматически отправляет пользователю файл материала.
3. Добавляет материал в раздел «💎 Мои покупки» — доступ сохраняется навсегда.
4. Уведомляет администратора о новой продаже.

## 8. Назначение администратора

Укажите Telegram ID администратора(ов) в `.env`:

```
ADMIN_IDS=111111111,222222222
```

Администратору доступны:

- `/broadcast` — рассылка сообщения всем пользователям (текст/фото/видео/документ)
- `/stats` — общая статистика бота
- `/sales` — статистика продаж по материалам
- `/users` — список пользователей
- `/find <имя или ID>` — поиск пользователя
- `/export` — выгрузка всех данных в Excel (.xlsx, отдельные листы)
- `/materials_admin` — добавление / удаление платных материалов, статистика продаж
- Кнопки под уведомлением о новой заявке: Принято / Открыть анкету / Профиль / Удалить

## 9. Добавление новых бесплатных статей

1. Создайте файл `articles/your_slug.md` с текстом статьи (Markdown).
2. Добавьте запись в список `ARTICLE_ORDER` в `services/article_service.py`:
   ```python
   ("your_slug", "📖 Заголовок статьи"),
   ```
3. Статья автоматически появится в разделе «📖 Бесплатные материалы».

## 10. Добавление новых платных материалов

Через бота: `/materials_admin` → «➕ Добавить материал» — бот запросит название,
описание, цену в Stars, файл и (опционально) обложку.

Либо вручную через `services/material_service.create_material(...)`, поместив файл
в `media/materials/`.

## 11. Важные ограничения бота (заложены в коде)

- Бот никогда не называет стоимость занятий — всегда отвечает, что цену можно узнать
  в Instagram или Telegram-канале (`handlers/faq.py`, `handlers/price_guard.py`).
- Бот не показывает телефон, email, WhatsApp или личный Telegram — только Instagram
  и Telegram-канал (`handlers/contacts.py`, значения берутся из `.env`).
- Бот не ставит диагнозы и не обещает сроков — все тексты в `handlers/about.py` и
  `data/faq.json` сформулированы без гарантий результата.

## 12. Безопасность

- Антиспам: `middlewares/throttling.py` ограничивает частоту сообщений от одного
  пользователя (`THROTTLE_RATE_LIMIT` в `.env`).
- Логирование ошибок: `middlewares/logging.py` перехватывает необработанные
  исключения, ошибки пишутся в `logs/bot.log` (ротация — 5 файлов по 5 МБ).
- Резервное копирование БД: при использовании SQLite достаточно регулярно копировать
  файл `data/bot.db`. Для PostgreSQL используйте `pg_dump` по расписанию (cron).
- Валидация ввода: числовые поля (цена материала, возраст) проверяются перед
  сохранением; свободный текст ограничен длиной полей БД.
